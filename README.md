# 달동이 뉴스봇 — 국내주식 버전 세팅 가이드

서버비 0원. 한 번 세팅하면 20분마다 알아서 돕니다. 컴퓨터 꺼도 돕니다.

---

## 1단계 — 봇 만들기 (3분)

1. 텔레그램에서 **@BotFather** 검색해서 대화 시작
2. `/newbot` 입력
3. 봇 이름 아무거나 (예: `달동이 뉴스`)
4. 아이디 입력 — 반드시 `bot`으로 끝나야 함 (예: `daldongi_news_bot`)
5. 이렇게 생긴 토큰이 나옵니다 → **복사해두세요**

```
7123456789:AAF-abcdefghijklmnopqrstuvwxyz123456789
```

---

## 2단계 — 그룹에 봇 넣고 chat_id 알아내기 (3분)

1. 달동이 패밀리 그룹 → 멤버 추가 → 방금 만든 봇 초대
2. **관리자로 승격** (필수는 아니지만, 그룹 권한 설정에 따라
   일반 멤버 봇은 전송이 막힐 수 있습니다. 관리자로 두는 게 안전합니다)
3. 그룹에 **`/start` 를 그대로 입력해서 전송**합니다

   ⚠️ 여기가 중요합니다. 봇은 기본적으로 **개인정보 보호 모드**가 켜져
   있어서 그룹의 일반 대화는 아예 받지 못합니다. `안녕` 같은 평범한
   메시지를 보내면 다음 단계에서 아무것도 안 나옵니다.
   `/` 로 시작하는 명령어는 이 모드와 무관하게 봇에 전달됩니다.

4. 브라우저 주소창에 아래 주소 입력 (`토큰` 부분만 본인 것으로 교체)

```
https://api.telegram.org/bot토큰/getUpdates
```

5. 나오는 글자 속에서 `"chat":{"id":-1001234567890` 를 찾습니다
   → **`-1001234567890` 이게 chat_id입니다.** 앞의 마이너스 포함해서 복사

> `{"ok":true,"result":[]}` 만 나오면: 3번에서 `/start` 를 안 보낸 겁니다.
> 보내고 새로고침하세요.

---

### 그룹이 아니라 채널에 보내고 싶다면

코드는 그룹·채널 둘 다 그대로 됩니다. chat_id 구하는 방법만 다릅니다.

- **공개 채널**이면 `@채널아이디` 를 chat_id 자리에 그대로 쓰면 됩니다.
  (예: `TELEGRAM_CHAT_ID` 값을 `@daldongi_family` 로)
- **비공개 채널**이면 봇을 채널 **관리자로 추가**(게시 권한 필요)한 뒤,
  채널 글 하나를 봇과의 1:1 대화로 **전달(forward)** 하고 `getUpdates` 를
  호출합니다. `forward_from_chat` 안의 `id` 가 채널 chat_id입니다.

채널은 관리자 권한이 **필수**입니다. 그룹과 달리 권한 없으면 아예 안 올라갑니다.

## 3단계 — GitHub 올리기 (5분)

1. github.com 로그인 → 우측 상단 `+` → **New repository**
2. 이름 아무거나 (예: `dal-news`), **Private** 선택, Create
3. 만들어진 화면에서 **uploading an existing file** 클릭
4. 이 폴더의 파일 전부 드래그해서 올리기
   - `bot.py`, `config.py`, `requirements.txt`, `README.md`
   - `.github` 폴더도 통째로 (이게 자동 실행 장치입니다)
5. **Commit changes** 클릭

> `.github` 폴더가 안 올라가면 자동 실행이 안 됩니다. 올라갔는지 꼭 확인하세요.

---

## 4단계 — 토큰 등록 (3분)

저장소에서 **Settings → Secrets and variables → Actions → New repository secret**

등록합니다:

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 그룹 chat_id (마이너스 포함) |
| `TELEGRAM_TOPIC_ID` | 주제방 번호 (주제 안 쓰면 등록 생략) |
| `ANTHROPIC_API_KEY` | 한 줄 코멘트용 API 키 |

이름 오타 나면 안 됩니다. 대문자 그대로.

`ANTHROPIC_API_KEY`는 `console.anthropic.com` → API Keys에서 발급합니다.
**이것만 안 넣어도 봇은 돕니다.** 코멘트 없이 제목 + 링크만 갑니다.

---

## 5단계 — 첫 실행 (1분)

**Actions** 탭 → 왼쪽 `dal-news` → **Run workflow** 버튼

- 첫 실행은 **최신 2건만** 보냅니다 (과거 기사 도배 방지 장치)
- 초록 체크 뜨고 그룹에 뉴스 2개 오면 성공
- 이후로는 20분마다 자동

빨간 X가 뜨면 그 실행을 클릭해서 로그를 보세요. 십중팔구 Secret 이름 오타입니다.

## 한 줄 코멘트

기사 본문을 복붙하지 않고, 제목 아래에 한 줄 관점만 얹는 구조입니다.
이렇게 나갑니다.

```
📑 두산에너빌리티 1조 유상증자 결정, 주가 8% 급락
└ 증자 자금이 설비인지 차입 상환인지에 따라 성격이 갈립니다.

#유상증자 · 서울경제 · 16:05 · 투자 권유 아님
https://n.news/...
```

이모지는 제목 내용에 따라 자동으로 갈립니다.
🚨 거래정지·서킷브레이커 / 📑 공시·실적 / 🏛 제도·정책 /
🔥 급등·신고가 / 📉 급락 / 🔄 수급 / 📈 지수

**코멘트에 못 쓰게 막아둔 것**

- 오른다·내린다·매수·매도·저평가·기회 같은 방향성 표현
- 제목에 없는 숫자·날짜·회사명·인용
- 충격·역대급 같은 과장 표현
- 제목을 다른 말로 바꿔 되풀이하는 요약

방향성을 막은 건 채널 원칙 문제만이 아닙니다. 유료 커뮤니티에
자동으로 매매 판단이 올라가면 그건 본인 책임이 됩니다. 사실 전달과
판단 유도는 선을 그어두는 게 안전합니다.

**조정하는 곳** — 전부 `config.py`

- `COMMENT_ON = False` → 코멘트 끄고 제목만
- `COMMENT_MAX_CHARS` → 코멘트 길이 (기본 60자)
- `FOOTER = ""` → 매 메시지 하단 문구 제거
  (채널 공지에 한 번 박아두는 방식으로 대체 가능)
- `COMMENT_PREFIX` → `└` 대신 다른 표시로

**코멘트가 이상하게 나오면** 그건 대부분 제목이 부실한 경우입니다.
봇은 **기사 제목만 보고** 코멘트를 씁니다. 본문을 읽지 않습니다.
그래서 코멘트는 "요약"이 아니라 "어디를 봐야 하는 사안이다" 수준의
맥락 한 줄입니다. 이 선을 넘게 만들려고 본문을 긁어오면 저작권
문제로 들어가고, 없는 사실을 지어내기 시작합니다. 지금 구조가
그 두 위험을 동시에 피하는 지점입니다.

**API가 죽어도 뉴스는 갑니다.** 코멘트 생성이 실패하면 그 회차만
코멘트 없이 제목+링크로 발송됩니다. 뉴스가 끊기지 않습니다.

## 평소 관리

**키워드 바꾸고 싶을 때** → `config.py` 파일만 수정하면 됩니다.
GitHub에서 파일 클릭 → 연필 아이콘 → 고치고 Commit. 다음 실행부터 적용됩니다.

**너무 많이 온다** → `config.py`에서
- `MAX_PER_RUN` 을 6 → 3 으로
- 키워드 줄이기 (`코스피`, `상한가`가 제일 많이 물어옵니다)
- 쓸모없는 단어를 `BLOCKLIST`에 추가

**너무 안 온다** → `MAX_AGE_HOURS`를 6 → 12로, 그리고 `EXTRA_FEEDS`에서
한국경제 증권 피드 줄의 `#`을 제거하면 증권 섹션 기사가 전부 들어옵니다.
`[특징주]` 기사를 다시 받고 싶으면 `BLOCKLIST`의 `"특징주"` 앞에 `#`을 붙이세요.

**밤에 알림 오는 게 싫다** → `QUIET_HOURS = (1, 7)` 숫자를 조정.
`(23, 8)`로 하면 밤 11시부터 아침 8시까지 침묵합니다. 끄려면 `None`.

**다른 기사인데 중복으로 잘려나간다** → `DUP_STOPWORDS`에 그 사건의
공통 단어를 추가하세요. 예를 들어 서로 다른 회사의 "수주" 기사가
서로를 잡아먹으면 `수주`를 목록에 넣으면 됩니다.

**같은 기사가 여러 번 온다** → `DUP_OVERLAP`을 0.40 → 0.30으로 낮춥니다.

## 국내주식 특유의 주의점

국내주식은 해외 뉴스와 오염 패턴이 완전히 다릅니다. 넣어둔 대응은 이렇습니다.

**1. 리딩방·주식카페 광고 기사**
"무료 추천주 대공개", "수익률 인증" 같은 보도자료가 뉴스로 유통됩니다.
`BLOCKLIST`에 20개 넘게 미리 넣어뒀고, 보도자료 유통사는 `BLOCK_SOURCES`로
매체 단위로 차단합니다. 새로운 패턴이 보이면 그때그때 추가하세요.

**2. `[특징주]` 자동생성 기사 — 기본 차단**
하루 수백 건 나오는 도배의 주범이라 `BLOCKLIST`에서 차단해뒀습니다.
급등 종목이 제일 먼저 뜨는 통로이기도 하니, 놓치는 게 아쉬우면
`"특징주"` 앞에 `#`을 붙여서 다시 켜세요.

**3. 같은 사건 중복**
국내 언론사는 같은 공시 하나로 10개 기사를 씁니다. 그래서 단순 제목
유사도로는 안 걸러집니다 — "삼성전자 영업이익"과 "SK하이닉스 영업이익"이
같은 사건인 "금투세" 기사 두 개보다 더 비슷하게 측정되기 때문입니다.
그래서 **주체 단어(회사명·지수명)가 겹치는지를 먼저 보고** 그 다음
전체 단어 겹침을 보는 2단 판정으로 짰습니다.

**4. 뉴스는 공시보다 느립니다**
유상증자·실적·대량보유 변동은 DART 공시가 먼저 뜨고 기사가 나중에 나옵니다.
빠르게 가려면 뉴스 대신 **DART 오픈API**(`opendart.fss.or.kr`, 인증키 무료)를
붙이는 게 정답입니다. 필요하시면 그 모듈을 따로 만들어 붙일 수 있습니다.

## 알아두실 것

- **cron 지연**: GitHub 무료 티어는 예약 실행이 5~15분 밀릴 수 있습니다. "20분마다"는 실제로 20~35분입니다. 초단위 속보용은 아니고 이슈 캐치용입니다.
- **저작권**: 제목 + 출처 + 원문 링크만 보냅니다. 본문 복붙이 아니라서 안전한 구조입니다. 나중에 요약을 붙이더라도 이 원칙은 유지하세요.
- **전송 제한**: 3초 간격 + 한 번에 6건 제한을 걸어놨습니다. 이거 풀면 텔레그램이 봇을 일시 차단합니다.
- **다른 텔레그램 채널 내용 퍼오기**는 이 봇으론 안 됩니다. 그건 본인 계정으로 로그인하는 유저봇 방식이라 계정 정지 위험이 있어서 빼놨습니다.
- **60일 방치 주의**: 저장소에 60일간 아무 커밋도 없으면 GitHub가 예약 실행을 자동 중단합니다. 이 봇은 `seen.json`을 계속 커밋해서 그럴 일은 없지만, 뉴스가 아예 0건인 상태가 두 달 이어지면 Actions 탭에서 한 번 눌러 되살리면 됩니다.
